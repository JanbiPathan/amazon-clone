# Amazon Clone

A responsive Amazon-inspired e-commerce website built using HTML and CSS. This project recreates the Amazon homepage with a modern user interface and multiple navigation pages to demonstrate front-end web development skills.

## 🚀 Features

- Responsive homepage layout
- Navigation bar with search functionality
- Product categories
- Account page
- Cart page
- Order page
- Contact page
- Clean and user-friendly interface
- Multiple interconnected web pages

## 🛠️ Technologies Used

- HTML5
- CSS3

## 📂 Project Structure

```
amazon-clone/
│── index.html
│── style.css
│── about.html
│── account.html
│── cart.html
│── contact.html
│── order.html
│── sign_in.html
│── image/
```
